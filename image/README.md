# 下位机编译版本

| 目录 | 说明 | Git 定位 |
|---|---|---|
| baseline-20261001 | 改造前真实 WSL 源码归档与板端自报 0.0.1 的程序、原启动脚本 | 随 3.1.0 发布提交保留；旧已提交基点 82e16b4 不是完整改造前源码 |
| v3.1.0-20261001 | 当前 3.1.0 程序、关键帧适配库、全部提示音（含 volume_test）、启动脚本和示例配置 | instrument-v3.1.0-20261001 |

在 WSL2 工程内运行 `./scripts/package_image.sh v3.1.0-20261001` 打包；已存在版本不会被覆盖。后续修改先更新代码版本，再创建新目录和对应标签。每个包内运行 `sha256sum -c SHA256SUMS` 校验。源代码以该标签的 Git 内容为准，Windows 副本只用于核对。

版本目录保存业务部署文件，不是整板烧录 update.img。安装与回滚见 deploy/README.md；不覆盖 Wi-Fi、现场配置、待传视频、事件和上位机新增记录。
