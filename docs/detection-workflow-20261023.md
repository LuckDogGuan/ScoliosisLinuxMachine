# 检测流程话术与协议（2026-10-23）

固件3.3.32 / Windows 3.3.36。业务源码与正式包以本WSL仓库为准，Windows UI与验收记录分别在对应仓库。

## 状态映射

- 电脑“开启检测” → capture_enable → 检测已就绪。
- 电脑“暂停检测” → capture_disable(reason=manual_stop) → 检测已暂停。
- 左右键有效检测操作 → 开始检测；单人正常完成 → 检测完成。
- 过短 → 时间不足，请重新检测；失败 → 检测未完成，请重试。
- 名单自然走到末尾 → capture_disable(reason=round_completed)静音，电脑播本轮检测已结束及本轮完成/跳过数，不代表整个班级完成。
- 用户点击“完成本班检测”并确认 → 电脑核对完整班级名单，每人至少存在未删除的成功采集回执或记录；不能靠性别、只展示未检测、跳过或单人模式绕过。暂停许可时静音，然后发送detection_class_complete(operation_id)。新固件播放本班检测已完成，电脑避免重复语音。旧固件/脱机由电脑播报兼容提示。
- 班级完成表示该班检测采集已完成；后台同步和分析可继续，不宣称所有分析/报告已生成。

## 长按提醒

已配对、同一已授权电脑最近15秒内通信，未开启检测且无诊断、采集、完成待处理或相机故障。左右键持续按住1500ms才入队，同次按住只一次，全局两次入队至少20000ms。断连/忙碌不入队。许可开启时取消已入队或正在播放的过时提醒。提醒不创建采集许可、不调用录像、不改变原800/1000/1200ms节奏或松键门禁。

## 协议与幂等

capture_disable的reason为可选，旧请求保持原暂停提示。detection_class_complete使用现有V3主机、IP、boot、sequence与nonce校验；还要求安全operation_id、检测许可关闭、无录像/完成待处理/诊断且提示队列有空间。相同operation_id在当前运行期再次请求成功返回而不重复播报；不作跨设备重启的持久去重承诺。新能力detection_status_voice_v1供上位机选择板端语音。

回滚可使用之前3.3.31正式包及本次安装器备份，须保留现场配置与待传数据。主机回归与编译不等同于物理按键、扬声器听感、真实拍摄上传或断电冷启动验收。实际构建和部署结果见Windows调试/记录/detection-workflow-20261023/。
