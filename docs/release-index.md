## 3.3.35 修改原因

真实安装版暴露待传分页16超过仪器上限8，以及电脑旧日志超预算后不能立即恢复保存的问题。上位机修复这两处；
仪器保留8条边界并返回明确错误invalid_pending_query/pending_storage_unavailable。打包VERSION.md从对应CHANGELOG条目生成，缺条目停止打包。

## 证据和回退

Windows调试仓库：调试/记录/fault-diagnostics-wifi-20261026/README.md、deployment.json及final/acceptance.json。
每版BUILD.txt绑定源码提交；tag指归档提交，两者职责不同。实际安装版本同时核对--version、installed-version、BUILD、运行文件哈希和hello能力。
每次安装沿用应用包安装器的备份目录和安装映射，配置、配对及待传材料保留。旧包用于回退；3.3.34原包保持不变。

3.3.36补充：忙碌回复不生成新故障、事件序号与协议序号分离、V3状态直接回读固件版本。旧3.3.34和3.3.35正式包保持原字节。

3.4.1为最终对齐补丁：上位机增加运行期屏幕1边界，仪器仅同步补丁号；3.4.0原包保留。最终源码/包/设备校验在交付时补齐。
